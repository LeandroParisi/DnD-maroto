Perfeito. Aqui está um **resumo do puzzle em formato de tabela**, pensado para você consultar rápido atrás do escudo do mestre, com **mecânica de urgência**, **elementos ficcionais**, **lapsos de visão**, **desejo de futuro** e **consequências claras**.

---

## Puzzle — **As Engrenagens do Tempo de Underhome**

| **Aspecto**                | **Descrição**                                                                  |
| -------------------------- | ------------------------------------------------------------------------------ |
| **Local**                  | Laboratório Anão Subterrâneo de Estudos Temporais (Underhome)                  |
| **Tema Central**           | Engrenagens do Tempo, determinismo vs livre-arbítrio, futuros possíveis        |
| **Objetivo dos Jogadores** | Sincronizar corretamente as Engrenagens do Tempo para abrir a saída da dungeon |
| **Falha Crítica**          | Forçar contradições temporais, quebrando a lógica da máquina                   |

---

## Estrutura do Puzzle

| **Elemento**                          | **Função no Puzzle**                             | **Risco Associado**                     |
| ------------------------------------- | ------------------------------------------------ | --------------------------------------- |
| **Engrenagem do Passado**             | Representa causas, memória e decisões já tomadas | Evoca erros antigos, visões traumáticas |
| **Engrenagem do Presente**            | Representa ação imediata e escolha               | Instabilidade física e temporal         |
| **Engrenagem do Futuro**              | Representa possibilidades e destinos             | Lapsos de visões de futuros possíveis   |
| **Eixo Central (Coração da Máquina)** | Sincroniza as engrenagens                        | Se sobrecarregado, acelera o colapso    |

---

## Mecânica de Urgência (Tempo Real)

| **Tempo Decorrido** | **Evento Negativo Automático**                                |
| ------------------- | ------------------------------------------------------------- |
| **0–3 minutos**     | O laboratório treme, poeira cai, relógios param               |
| **3–6 minutos**     | Um personagem sofre um lapso temporal (visão curta e confusa) |
| **6–9 minutos**     | Uma engrenagem gira sozinha, alterando uma decisão feita      |
| **9–12 minutos**    | A máquina entra em estado de contradição parcial              |
| **12+ minutos**     | Colapso: a Engrenagem do Futuro se fragmenta                  |

> 💡 **Dica de Mesa:** use um cronômetro visível para os jogadores.

---

## Lapsos de Visão (Futuros Possíveis)

| **Visão**       | **O Que Revela**                       | **Custo Narrativo**                     |
| --------------- | -------------------------------------- | --------------------------------------- |
| **Destino I**   | Ordem rígida imposta pelas Engrenagens | Perda gradual de livre-arbítrio         |
| **Destino II**  | Dominação Drow e corrupção do mundo    | Realização de desejos de forma perversa |
| **Destino III** | Destruição das Engrenagens             | Existência eterna sem morte             |

---

## Mecânica do Desejo de Futuro

| **Ação**                     | **Efeito**                             | **Preço Oculto**              |
| ---------------------------- | -------------------------------------- | ----------------------------- |
| Um jogador declara um desejo | A Engrenagem do Futuro se alinha a ele | Cria uma contradição temporal |
| Dois desejos compatíveis     | Reduz o tempo de colapso               | O futuro se torna mais rígido |
| Desejos conflitantes         | Acelera o colapso                      | Aproxima o Destino III        |
| Desejo egoísta               | Benefício imediato                     | Custo moral no futuro         |

---

## Condições de Sucesso

| **Resultado**         | **Consequência**                       |
| --------------------- | -------------------------------------- |
| Sincronização parcial | Saída abre, mas um futuro é selado     |
| Sincronização correta | Saída abre, futuros permanecem fluidos |
| Manipulação cuidadosa | Revela pistas sobre o Anão Misterioso  |

---

## Falhas e Consequências

| **Falha**          | **Resultado Narrativo**           |
| ------------------ | --------------------------------- |
| Forçar engrenagens | Visão forçada do Destino III      |
| Ignorar lapsos     | Decisões futuras perdem efeito    |
| Tempo esgotado     | Engrenagens entram em contradição |
| Quebra total       | Consciência fragmentada no caos   |

## Uso Dramático em Mesa

| **Ferramenta**              | **Como Usar**                         |
| --------------------------- | ------------------------------------- |

| Visões narradas             | Direcionam escolhas sem dar respostas |
